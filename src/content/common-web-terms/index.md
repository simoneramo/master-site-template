    definition: >-

  - icon: "\U0001F3E0"
    term: Hosting
    definition: >-

  - icon: "\U0001F5A5️"
    term: Server
    definition: >-

  - icon: "\U0001F9ED"
    term: Browser
    definition: >-
      The software you use to access the internet, such as Google Chrome,
      Safari, or Microsoft Edge.
  - icon: "\U0001F522"

  - icon: "\U0001F4D2"

  - icon: ☁️
    term: Cloud
    definition: >-
      A network of remote servers used to store and manage data over the
      internet instead of on your local hard drive.
  - icon: "\U0001F3A8"
    term: UI
    definition: >-

      buttons, fonts, and colours.
  - icon: "\U0001F60A"
    term: UX
    definition: >-
      User experience. The overall feeling and ease of use a customer has when navigating through
      your website to find information.
  - icon: "\U0001F4F1"
    term: Responsive design
    definition: >-
      A layout technique that ensures your website automatically shrinks or
      expands to look perfect on any screen size.
  - icon: "\U0001F4F2"
    term: Mobile-first
    definition: >-
      The strategy of designing your website for smartphone users before
      adapting it for larger desktop screens.
  - icon: "\U0001F516"

    definition: >-
      The tiny logo icon that appears next to your website title in a browser
      tab.
  - icon: "\U0001F9B8"

    definition: >-

  - icon: "\U0001F5FA️"
    term: Navigation menu
    definition: >-

  - icon: "\U0001F9B6"

    definition: >-

  - icon: "\U0001F4E3"
